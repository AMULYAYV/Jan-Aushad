# Jan-Aushadhi Finder 💊

Jan-Aushadhi Finder is an AI-powered Android healthcare application designed to help users easily locate nearby Jan Aushadhi stores, search affordable generic medicines, track medicine refills, and get healthcare assistance using Generative AI.

The application aims to improve accessibility to low-cost medicines and simplify healthcare support for users through modern Android technologies and AI integration.

---

## 🚀 Features

- 🔍 Search medicines available in Jan Aushadhi stores
- 📍 Find nearby Jan Aushadhi Kendras using location services
- 🤖 AI-powered healthcare assistant using Google AI Studio / GenAI
- 💊 Medicine refill tracker and reminders
- 🏥 Store details with directions and contact information
- 📱 Simple and user-friendly Android interface
- ☁️ Firebase/Backend integration for data handling
- 🔐 Secure and responsive application design
