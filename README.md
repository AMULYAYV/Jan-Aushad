# Jan Aushadh1

Jan Aushadh1 is an Android application that provides a seamless interface to the ZenHealth platform using a WebView.

## Features

- **WebView Integration**: Access the ZenHealth web platform directly within the app.
- **Back Navigation**: Optimized back button handling to navigate through WebView history.
- **Lightweight**: Minimalist design and efficient resource usage.

## Getting Started

### Prerequisites

- Android Studio Koala or newer.
- JDK 11 or higher.
- Android SDK API Level 24+ (Android 7.0).

### Building the Project

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Open the project in Android Studio.
3. Sync the project with Gradle files.
4. Run the app on an emulator or a physical device.

## Technologies Used

- **Kotlin**: Primary programming language.
- **Jetpack Compose**: Used for the UI framework.
- **Android WebView**: For displaying web content.
- **Gradle**: Build automation system.
